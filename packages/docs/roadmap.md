This docs describes a roadmap of features for the mentally app.

### MVP

- Waitlist page with email recordings
- Mood note CRUD front-end
  1. Mode note page overview
  2. Table with all mood notes
  3. Create mood note screen
  4. Analysis tabs for mood notes
  - Avg. mood based on timeframe
  - Best mood activity
  - Worst mood activity
  5. Tests CRUD pages
  - Test analysis page
  - Last test scores
  - Recomended tests
  - Complete the test
  6. Onboarding page
  7. User avatars features
  - Avatar core art and animations
  - Avatars work rules (when happy, tired, sad, growing, etc);
  - Avatar choice on the registration
  - Avatar page
